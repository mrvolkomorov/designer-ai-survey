# Входная анкета — Дизайнер и ИИ

Входная анкета для индивидуального обучения дизайнера работе с ИИ-инструментами.

Анкета: https://mrvolkomorov.github.io/designer-ai-survey/

## Что внутри

- 8 содержательных блоков, ~29 вопросов, 7–9 минут заполнения
- Убраны служебные вопросы (сфера, должность, стаж — известны)
- 5 кейсов из реальной дизайнерской практики
- Под специфику 4 инструментов из набора: Genspark, Recraft, Stable Diffusion (Fooocus/RunDiffusion), Canva

## Сбор ответов

Ответы отправляются в Google Таблицу через Google Apps Script Web App. URL скрипта хранится в `index.html` в строке `const SCRIPT_URL = "..."`.
